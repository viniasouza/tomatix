A TOMATIX é uma solução de tecnologia voltada para produtores de tomate em estufas.

O projeto utiliza sensores e uma plataforma de monitoramento para acompanhar a luminosidade durante o cultivo, permitindo visualizar dados, identificar variações e receber alertas para auxiliar na tomada de decisões em cada etapa do desenvolvimento da planta.

Objetivo

Desenvolver uma solução acessível e inteligente que transforme dados de luminosidade em informações úteis para melhorar o acompanhamento do cultivo de tomate em estufas.

Principais recursos

Monitoramento da luminosidade em tempo real;

Registro e visualização dos dados;

Alertas quando os níveis estiverem fora do ideal;

Acompanhamento das diferentes fases do cultivo;

Plataforma para análise e tomada de decisões.
